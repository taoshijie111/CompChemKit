# 平台专属说明：模板

复制成 `platforms/<集群短名>.md`，然后在 `~/.compchemkit/config.json` 里用
`"notes_file": "platforms/<集群短名>.md"` 指过来。

写法要求：

- **只写这个集群特有的东西**。通用的坑（CRLF、脚本被复制到 spool、`--mem` 报错、
  看门狗机制…）写在 `SKILL.md`，这里不要重复。
- 每条都按「现象 → 原因 → 处理」写，带上**实测日期**，方便以后判断是否还成立。
- 不写账号、密码、真实 home 路径；路径写成 `<WORKDIR>`、`$HOME` 之类的占位。
- 如果某条已经被集群管理员修好，划掉并注明日期，不要直接删。
